Получение ключа ВК для уведомлений

Страница не отправляет ключи на GitHub и никуда их не сохраняет. После входа ключ показывается только здесь. Скопируйте его прямо в секрет GitHub VK_ACCESS_TOKEN. Если ВК не выдаст разрешение на сообщения, эта связка не сможет читать беседы.

Ключ ВК

Скопируйте значение в закрытый секрет GitHub VK_ACCESS_TOKEN. Не отправляйте его в чат и не сохраняйте в файлах.
